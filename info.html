About this project

This page aims to collect and share the current state of the art Industrial Control Systems (ICS) Testbed and Datasets

We think that this collection can help the ICS security community see the current research trend worldwide and find useful information to support future studies.

Testbed types: We collect three types of testbeds.

  • Physical Testbed: composed of real hardware and software to configure both the network and physical layers. They are a suitable approach when researchers need a solution to collect realistic measurement variation and latencies.
  • Virtual Testbed: leverage software simulations and emulations with single or multiple programs to reproduce the entire network and all the different components. A virtual testbed represents a low-cost solution, but it is not easy to simulate high fidelity physical processes due to the virtualized environment. Despite this lack of precision, dangerous and risky processes (e.g., Nuclear sector) can be, in this way, simulated in a laboratory.
  • Hybrid Testbed: are composed of both physical devices and software simulations. This approach represents a good trade-off between physical and virtual solutions and is called a hybrid testbed. The main difference between the complete physical testbeds is that part of the physical processes and/or components are simulated using specialized software.

We also collected the various datasets in the literature. Since collecting or retrieving an ICS testbed is a difficult task, we hope this page can help researchers identify the most suited for research.

Reference/Publication

Conti, M., Donadel, D., & Turrin, F. (2021). A survey on industrial control system testbeds and datasets for security research. IEEE Communications Surveys & Tutorials, 23(4), 2248-2294.

This paper provides a comprehensive overview of the existing ICS testbeds and datasets available for security research collected until 2021.

Also on Arxiv: https://arxiv.org/abs/2102.05631

Update Request

To add a new dataset or testbed, the preferred method is to submit a pull request to this repository. If you have any doubts, questions, or need assistance, please contact: denis donadel at gmail com

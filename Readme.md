# Awesome Testbeds and Datasets for ICS Research

![awesome badge](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg) ![last-commit-main](https://img.shields.io/github/last-commit/awesomeics/awesomeics.github.io/main)

A curated list of testbeds and datasets for research in industrial control systems


## Contributing
To contribute, send a pull request adding your testbed or dataset in `_data/testbeds.yml` or `_data/datasets.yml`. 
Statistics in the `info.html` page will be regenerated automatically. 

In case of testbeds, for the time being, please replace `&` in citations with `%26`, otherwise it will break links to Google Scholar.
